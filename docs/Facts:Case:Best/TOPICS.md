# Справочник тем/ниш (knowledge.topic)

Версия: v1

Используется LLM-проходом `llm:validate knowledge` как whitelist для поля `topic`.
Модель обязана вернуть **одну** тему из списка ниже или `null`, если чанк не
относится ни к одной из ниш. Значения — короткие метки (одно слово/фраза),
дословно как в списке.

## Темы

- `контентные сайты` — создание и развитие информационных сайтов, контент, редактура, ТЗ.
- `монетизация` — реклама (РСЯ, прямые рекламодатели), офферы, продажа ссылок, доход с площадок.
- `обучение` — курсы, марафоны, семинары, наставничество, работа с потоком учеников.
- `трафик` — привлечение аудитории, поиск, продвижение, конференции по трафику.
- `делегирование` — регламенты, стандарты, KPI, команда, передача рутины, операционные процессы.
- `предпринимательство` — стратегия, фокус на ключевых действиях, новые направления, управление бизнесом.
- `реинвестирование` — реинвестирование прибыли, сложный процент, кассовые разрывы, портфель проектов.
- `личный бренд` — публичный блог, открытость, путь основателя, доверие аудитории.
