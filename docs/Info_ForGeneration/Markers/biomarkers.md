# Био-маркеры

Делают кейс «человеческим». **Каждый найденный маркер в тексте чанка → + к `human_factor`.**

Поиск через регекс / substring match.

---

## Возраст

- N лет (любое число от 30 до 80 + «лет»)
- «в N лет», «в 40», «в 50», «в 60», «в 70»
- «пенсионер», «пенсионерка», «на пенсии», «после выхода на пенсию»

## Семейные обстоятельства

- «жена», «муж», «супруга», «супруг»
- «дети», «N детей», «пятеро детей», «двое детей», «трое детей»
- «школьник», «школьница», «подросток», «студент», «студентка»
- «один воспитывает», «один растит», «одна растит»
- «бабушка», «дедушка», «внуки», «внучка», «внук»
- «беременность», «декрет», «в декрете», «после декрета»
- «развод», «развелись», «вдова», «вдовец»
- «родители», «мать», «отец», «папа», «мама»

## Профессия (обычная для аудитории 40-65)

- «врач», «медсестра», «фельдшер»
- «учитель», «учительница», «воспитатель», «логопед»
- «инженер», «техник», «механик»
- «бухгалтер», «экономист», «специалист»
- «менеджер» *(оговорка: только если в контексте обычной работы)*
- «продавец», «продавщица», «кассир», «бариста», «официант», «официантка»
- «водитель», «таксист», «водитель грузовика», «дальнобойщик»
- «военный», «офицер», «военнослужащий», «отставник»
- «слесарь», «электрик», «строитель», «сантехник», «монтажник»
- «парикмахер», «маникюрщица», «массажист», «косметолог»
- «уборщица», «охранник», «дворник», «вахтёр»
- «фермер», «дачник», «садовник»
- «бухгалтер», «архивариус», «библиотекарь»

**ИСКЛЮЧЕНЫ как «не обычные» для нашей аудитории:**
программист, айтишник, сисадмин, маркетолог, SMM-щик, веб-мастер, дизайнер UX, продакт.

## Тип занятости

- «работа основная»
- «на двух работах»
- «полная смена», «8 часов рабочий день»
- «5 дней в неделю», «по сменам», «сутки через трое»
- «вечером после работы», «по выходным», «в свободное время»
- «во время декрета», «параллельно с работой», «между сменами»
- «на пенсии», «после выхода на пенсию»

## Здоровье / физические особенности

- «инвалид», «инвалидность», «I группа», «II группа», «III группа»
- «диабет», «онкология», «после операции», «реабилитация»
- «травма», «коляска», «слабовидящий», «слабослышащий», «ОВЗ»
- «болеет», «болезнь», «хронические»

## Место / география

- «из Беларуси», «из Казахстана», «из Узбекистана», «из Армении», «из России»
- «из деревни», «из села», «маленький город», «N тысяч жителей»
- «провинция», «глубинка»
- «эмигрировал», «переехал»

## Финансовая база (исходная)

- «зарплата N тысяч» (если N ≤ 50)
- «получал N в месяц» (если N ≤ 50)
- «жил на пенсию»
- «ипотека», «кредит», «долги», «должен банку», «в долгах», «микрокредиты»
- «копил годами»
- «жил впритык», «жил от зарплаты до зарплаты»

## Стартовая ситуация

- «никогда не работал в интернете»
- «без образования», «без диплома», «без высшего»
- «без английского»
- «без компьютера»
- «впервые», «с нуля», «с чистого листа»
- «ничего не умел», «не разбирался»
- «гуманитарий»
