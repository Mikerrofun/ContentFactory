- **Что значит:** общая техническая чистота (длина/формат/жаргон/AI-маркеры/числа).

### 2. human_factor — человечность
- **Что значит:** возраст/семья/эмоции (живой человек, не робот).
- **Как:** regex по biomarkers+emotional → `1−exp(−count/5)`.
- **Источник:** `Markers/biomarkers.md`, `Markers/emotional_markers.md`.
- **Где:** [В] [ВЫБ] [ОБУЧ].

### 3. adaptability — снятие страхов
- **Что значит:** закрывает страхи аудитории, без жаргона.
- **Как:** (fear/3) − жаргон − «доход без био».
- **Источник:** `Markers/fear_markers.md`, `Markers/anti_markers.md`, `AUDIENCE.docx`.
- **Где:** [В] [ВЫБ].

### 4. number-guard violation — нет выдуманных чисел
- **Что значит:** все числа из базы, не выдуманы.
- **Как:** извлечь числа → сверка с FACTS; нет → violation.
- **Источник:** `PRODUCT_FACTS.md`, `FACTS.docx`, `GUARDRAILS.docx`.
- **Где:** [В] [ВЫБ] [УЧ].

### 5. style-близость — похоже на автора

### 6. 5-тактная полнота — структура
