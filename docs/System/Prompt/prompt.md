# Промпт + самокритика (Этап 4)

Статус: черновик v1. Связка: Этап 1 (бандл) → Этап 4 (промпт) → Этап 2 (валидация) → Этап 3 (обучение).

Главное:
1. Промпт = **2 части: системная (постоянная) + динамическая (на пост).**
2. Летит максимум: активные правила + бандл (5 слотов) + voice-примеры диалогов + гард.
3. Самокритика: модель смотрит все 17 метрик (часть — по документам/маркерам, часть — модели).
4. **2-3 раунда** доработки.
5. **Разные модели:** генерация сильная, критик лёгкая (OpenRouter).
6. Провал после N раундов → копирайтеру.

---

## 1. Структура промпта (2 части)

### Системная часть (постоянная, версионируется)
- Роль/голос автора (VOICE).
- Активные правила (global + тип) из базы знаний (Этап 3).
- Гард: FACTS + PRODUCT_FACTS + GUARDRAILS.
- 5-тактная структура + метрики качества (что важно).
- Базовый стиль (STANDARD: длина, абзацы, эмодзи, CTA).

### Динамическая часть (на каждый пост)
- Тема/якорь + тип поста.
- Бандл 5 слотов: якорь / факты-доноры / кейс / voice-эталоны / морф-шаблон.
- Voice-примеры диалогов (как автор ведёт диалог).
- Audience-фразы под страх.
- Конкретные факты/числа (number-guard).

---

## 2. Что летит в генерацию (максимум)

| Что | Источник | Зачем |
|---|---|---|
| Активные правила | база знаний (Этап 3) | точнее стиль |
| Бандл 5 слотов | Этап 1 | фактура/кейс/стиль/шаблон |
| Voice-диалоги | `Архив/VOICE.docx` | как автор говорит |
| Гард | FACTS/PRODUCT_FACTS/GUARDRAILS | не выдумывать |
| Структура/тип | Этап 2 | 5 тактов |
| Эталоны few-shot | `Архив/BEST.docx` | стиль |

Проверки (Этап 2) — обязательны, по документам/маркерам.

---

## 3. Самокритика

После генерации — лёгкая LLM-критик:
- Смотрит пост + 17 метрик.
- Часть метрик — по документам/маркерам (1-4, 11-13, 14-17), часть — модель (5, 8).
- Возвращает флаги по тактам + fix_hint.
- 2-3 раунда: генерация → самокритика → доработка проблемного такта → повтор.
- Провал после N (2-3) раундов → копирайтеру.

---

## 4. Модели
- Генерация: сильная модель.
- Критик: лёгкая (OpenRouter, копейки).
- Разные — экономия + строже проверка.

---

## 5. Связка с обучением
- Версии промпта/стиля фиксируются в эпизоде (Этап 3).
- fix_hint и флаги → материал для правил (Этап 3).
- Активные правила подставляются в системную часть динамически.
