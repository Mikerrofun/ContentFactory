# Контент-завод — план реализации (v5)

По пунктам: что реализовывать. Каждый пункт = этап, со ссылкой на док и описанием. Нерелевантное из v3 отсеяно.

## 1. Чанкование
Док: `docs/System/Chunks/chunks.md` + `chunkPresentation.md`.

Что делать:
- 6 типов, 2 класса: ядра (`knowledge`, `case`) + эталоны (`fact`, `voice`, `swipe`, `audience`).
- Единая схема полей + type-specific.
- Износ: knowledge по фактам; case полный; эталоны почти нет.
- 5 ролевых слотов контекста.
- Нарезка: knowledge блоки+факты; остальное целиком.
- Индексация: эмбеддинги фактов+чанка, поля type-specific.

## 2. 5-тактная валидация
Док: `docs/System/Validation/validation.md` + `validationRecon.md` + `validationPresentation.md`.

Что делать:
- 5 тактов (Хук/Рамка/Ядро/Доказательство/Финал).
- Детерм-чекеры + лёгкие LLM (OpenRouter).
- 17 метрик (13 качества + 4 разнообразия).
- Вердикт + флаги по тактам; любой fail = fail.
- ~5 генераций → лучшая; перегенерация такт→пост.

## 3. Самообучение
Док: `docs/System/Learning/learning.md` + `learningPresentation.md`.

Что делать:
- 3 слоя: правила / веса / эпизоды.
- Гибрид правил+весов, скоуп 2 уровня.
- Исключения с TTL по правкам; порог по окну + сила (LLM).
- Отмена = вето-вес; откат через `weight_delta`.
- Веса по preference, демпфирование.

## 4. Промпт + самокритика
Док: `docs/System/Prompt/` (создать).

Что делать:
- Сборка промпта из бандла (5 слотов) + правила + эталоны + гард.
- Самокритика: 1 лёгкий LLM-проход, флаги по тактам.
- Фиксация версий промпта/стиля.

## 5. Учёт после человека + 3 поста/день
Док: `docs/System/Accounting/` (создать).

Что делать:
- 3 темы одного типа → 5 генераций → выбор лучшей → копирайтеру.
- После человека: эпизод, diff, preference, износ, Edit Distance.
- Прокачка типа + глобальная.

## 6. Архитектура / стек / UX / бот
Док: `docs/System/Architecture/` (создать).

Что делать:

- Асинхронный воркер индексации (очередь/ретраи/статус).
- Хранение: единая схема + type-specific.
