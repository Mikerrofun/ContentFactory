# Контент-завод — план реализации (v6)

По пунктам: что реализовывать. Каждый пункт = этап, со ссылкой на док. Нерелевантное из v3 отсеяно.

---

## 1. Чанкование
Док: `docs/System/Chunks/chunks.md` + `chunkPresentation.md`.

- 6 типов, 2 класса: ядра (`knowledge`, `case`) + эталоны (`fact`, `voice`, `swipe`, `audience`).
- Единая схема полей + type-specific (`facts[]`, `fear_closed`, `s_scheme`, `format`).
- Износ: knowledge по фактам; case полный; эталоны почти нет.
- 5 ролевых слотов контекста.
- Нарезка: knowledge блоки+факты; остальное целиком.
- Индексация: эмбеддинги фактов+чанка, поля type-specific.

## 2. 5-тактная валидация
Док: `docs/System/Validation/validation.md` + `validationPresentation.md`.
Метрики: `docs/System/Metrics/metrics.md`.

- 5 тактов (Хук/Рамка/Ядро/Доказательство/Финал); общие Хук/Ядро/Финал, type Рамка/Доказательство.
- Детерм + лёгкие LLM (OpenRouter). Любой fail такта = fail.
- 17 метрик (13 качества + 4 разнообразия 14-17) — карта в validation.md, описание в metrics.md.
- Защита от mode collapse: ритм/словарь = коридор, не точка; мягкий сигнал; по тактам.
- ~5 генераций → лучшая; перегенерация такт→пост.

## 3. Самообучение
Док: `docs/System/Learning/learning.md` + `learningPresentation.md`.

- 3 слоя: правила / веса / эпизоды; каждое решение трогает все.
- Гибрид правил+весов, скоуп 2 уровня (global/type).
- Исключения с TTL по правкам; порог по окну + сила влияния (LLM).
- Отмена = вето-вес; откат через `weight_delta`; авто-откат по метрикам.
- Веса по preference, демпфирование.

## 4. Промпт + самокритика
Док: `docs/System/Prompt/prompt.md`.

- 2 части: системная (голос/правила/гард) + динамическая (бандл/тема/тип).
- Летит максимум: правила + 5 слотов + voice-диалоги + гард + эталоны.
- Самокритика: лёгкая LLM смотрит 17 метрик (часть по докам/маркерам), 2-3 раунда.
- Разные модели: ген сильная, критик лёгкая. Провал после N → человеку.
- Фиксация версий промпта/стиля.

## 5. Учёт после человека + 3 поста/день
Док: `docs/System/Accounting/accounting.md`.

- 3 разных якоря одного типа → 5 генераций на каждый (15).
- Выбор лучшей: 17 метрик + LLM-ранжирование (веса Этапа 3).
- 3 лучших → копирайтеру (выбор/правки).
- После полных правок: эпизод (полный) + правки в базу (Этап 3) + износ + подбивка.
- Износ: knowledge/case полный; факты/swipe cooldown; voice/audience без.

## 6. Архитектура / стек / UX / бот
Док: `docs/System/Architecture/` (создать).

- Next.js (бэк+фронт+админка).
- Telegram-бот (голос/файлы→БД).
- Асинхронный воркер индексации (очередь/ретраи/статус).
- Хранение: единая схема + type-specific.
