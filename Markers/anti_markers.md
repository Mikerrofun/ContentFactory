# Анти-маркеры

Маркеры, которые **снижают `adaptability`** для L1-L2 контента. Они делают кейс слишком техническим, абстрактным или невероятным для аудитории 40-65.

**Каждый найденный маркер → − к `adaptability`.** Если 3+ маркеров в чанке — сильное снижение score для L1-L2 use.

## 3. Большие цифры дохода — контекстный пенальти

**Это особый случай.** Не безусловное снижение, а **контекстный**:

- «миллион в месяц», «N миллионов»
- «700 тысяч», «800 тысяч», «900 тысяч»
- Любое значение **> 500 000 руб/мес** как абсолютная финальная цифра

**Логика контекстного пенальти:**

```
if (high_income_marker found):
    if (количество био-маркеров < 3):
        adaptability -= 0.10  # пенальти срабатывает
    else:
        adaptability -= 0.00  # компенсировано контекстом
```

**Пример компенсации:**
Владимир врач, 5 детей, Швеция, 8-часовая смена, параллельно с работой → 3к → 300к. Цифра 300к попадает в диапазон, но компенсируется био-маркерами (врач + 5 детей + работа + Швеция) → пенальти не срабатывает.

**Пример срабатывания:**
Чанк говорит: «вышел на 700 тысяч в месяц», без упоминания возраста, семьи, профессии, начальной ситуации → пенальти срабатывает, кейс не подходит для L1-L2 standalone.

**Phase 3 (отдельно):**
В будущем заменим контекстный пенальти на **выбор этапа из income_milestones** — будем подавать ранний этап того же кейса (например, тот же Алексей подавался на момент «150 тыс/мес», когда это было правдой).
