# STYLE_TRANSLATION — словарь замен лексики

Версия: v1
Принят: 2026-05-27
Назначение: словарь пар «AI говорит → Пузат говорит», который читается генератором перед написанием поста и используется для замены проблемных формулировок.

## Принципы

- Это **подсказка предпочтения**, не строгое правило. Контекст важен — одна и та же фраза в разных постах может оставаться или меняться.
- Пополняется через lessons-loop после каждой серии (см. Phase 5 spec, секция 4).
- Если новая запись не вписывается ни в одну из существующих категорий — создай новую секцию `## <название категории>`, не сжимай искусственно в чужую.
- Каждая запись сопровождается источником: `(добавлено из правки серии YYYY-MM-DD, пост N)`.

| AI говорит | Пузат говорит | Почему |
|---|---|---|
| работодатель | начальник | разговорнее, ближе к аудитории |
| разговор с работодателем | разговор с начальником | то же |

*Источник: правка серии 2026-05-27, пост 1*

## Лексика — абстракция → конкретный страх / реалия

| AI говорит | Пузат говорит | Почему |
|---|---|---|
| не часы и не знания | нет времени, нет знаний | названы реальные страхи аудитории (из AUDIENCE.md) |
| часов у людей в избытке | времени у людей в избытке | у аудитории нет «часов», есть «время» |

*Источник: правка серии 2026-05-27, пост 1*

## Образность — поэзия → прямота

| AI говорит | Пузат говорит | Почему |
|---|---|---|
| та, что осталась стоять | та, которая на самом деле давно остановилась | прямее + «на самом деле» = характерный переходник Пузата |
| родители смотрят серьёзно | родители переживали / увидели в этом серьёзность | внутреннее состояние, не наблюдаемый жест |

*Источник: правка серии 2026-05-27, пост 1*

## Именование сцены (вместо описания жеста)

| AI говорит | Пузат говорит | Почему |
|---|---|---|
| Принял решение и сделал шаг навстречу | Одно из первых взрослых, сложных решений. Я уволился. | конкретная сцена вместо обобщённого жеста |

*Источник: правка серии 2026-05-27, пост 1*

⚠️ **Уточнение от правки v2:** правило про «именование сцены» НЕ применяется к понятным концептуальным фразам типа **«пойти навстречу страху»**. Это работающая концепция, а не жест-обёртка. Заменять её на «сделать страшное» — over-correction. См. VOICE_FINGERPRINT.md Правило 1.

## Сложно → проще (читаемость 40+)

Книжные / длинные слова → бытовые эквиваленты. Это про **тяжесть текста** — когда «приходится продираться сквозь предложения».

| Сложно (книжно) | Проще (разговорно) | Почему |
|---|---|---|
| банальность | обычная вещь / все это знают | книжное → разговорное |
| реальность сменилась | жизнь стала другой | книжное → бытовое |
| звенящем состоянии | другое ощущение / напряжение | образно, но затруднённо |
| структурный / концептуальный / экзистенциальный | (упрощать или удалять) | абстрактные термины из эссе |
| жизнь шла иначе | жизнь менялась | книжный глагол → активный |
| постреливает (про зуб) | беспокоит | образно, но непонятно для 40+ |
| видно | становится видно | сокращённая связка → полная разговорная |
| подавление мышления | ограничения себя | книжное → разговорное |
| собственного «давай ещё подумаю» | бесконечного обучения вместо действий | расшифровка внутренней реплики |
| технологически сложное | сложное | «технологически» — лишнее книжное наречие |
| держит (про опору) | даёт свободу | конкретное благо вместо абстракции |
| не получалось | усилий много, а денег нет | конкретизация через контраст усилие/результат |

*Источник: правки 2026-05-27, пост 1 v2 + v3*

⚠️ Главный принцип — см. VOICE_FINGERPRINT.md Правило 6 «Простые короткие предложения». Эта таблица — частные случаи общего правила.

## Голоса аудитории — из её лексикона

Когда цитируешь **внутренние реплики читателей** — бери реальный лексикон аудитории 40+ из `knowledge/markers/fear_markers.md` и `knowledge/AUDIENCE.md`, не интеллигентные обороты.

| AI говорит (интеллигентно / сжато) | Пузат говорит (как аудитория реально думает) |
|---|---|
| «когда созрею» | «поздно мне уже» |
| «когда станет понятнее» | «наверно у меня не получится» |
| «надо подождать» | «в следующий раз» |
| «я не готов» | «я уже стар для этого» |
| «нужно поразмыслить» | «попозже подумаю» |
| «улучшить» | «сделать как-то по своему» |
| «понять глубже» | «сначала всё изучить, а потом делать» |
| «копает глубже» | «думает, что ему нужно что-то изучить, прежде чем начать делать» |
| «всё ещё не готов» | «давай ещё подумаю» / «теперь я готов» (когда снова отодвигается) |

⚠️ **Уточнение v5:** цитаты внутренних реплик должны быть **развёрнутыми фразами**, как читатель реально проговаривает их про себя. Не сжатыми концепциями («улучшить» — это AI; «сделать как-то по своему» — это как реально думает человек).

**Источник истины:** конкретные fear-markers из `knowledge/markers/fear_markers.md` (особенно «Поздно», «Не справлюсь», «Впустую потрачу»). Цитаты должны быть **узнаваемы** для аудитории как «это про меня».

*Источник: правка серии 2026-05-27, пост 1 v3 — пользователь*

## Разговорные интенсификаторы (добавляй для разговорности)

Это **что добавлять**, не «было → стало». Короткие связки которые делают предложение разговорнее.

| Нейтрально | Разговорнее | Когда добавлять |
|---|---|---|
| Первая запись в трудовой | **Это же** первая запись в трудовой | подчеркнуть значимость через «это же» |
| Зуб болит | **И вот** зуб начинает болеть | переход во времени |
| Не получилось | **Надо же**, не получилось | удивление / разочарование |
| Знаете, я... | **Слушайте**, я... | разговорное вступление |
| А результата нет | А **вот** результата нет | живое противопоставление с «А вот» |
| Разница не в X. Не в Y. | **И при этом** разница не в X **и** не в Y. | связка логически связанных мыслей |
| (новая тема) | **Кстати**, ... / **Знаете что**, ... | плавный переход к новой мысли |
| параллельно работа, семья | параллельно **ведь** есть работа, семья | «ведь» — мягкое усиление |
| До результата — строго по схеме | **А** до результата — строго по схеме | связка «А» для противопоставления |

⚠️ Не злоупотреблять — 1-2 интенсификатора на пост, иначе становится сюсюканием.

*Источник: правка серии 2026-05-27, пост 1 v3 — пользователь*

## Конкретные чувства вместо абстракций

Когда описываешь результат / следствие — называть **конкретное чувство** или ощущение, не абстрактный концепт.

| Абстрактно | Конкретно (Пузат) | Почему |
|---|---|---|
| новая жизнь (появится) | новая энергия | чувство, не философия |
| новая реальность | другое ощущение / напряжение | сенсорно |
| смысл проявится | ясность придёт | конкретный когнитивный момент |
| всё откроется | начнёшь видеть | действие, не пассив |

*Источник: правка серии 2026-05-27, пост 1 v3 — пользователь*

## Оценочные позитивные добавления

Нейтральные существительные стоит «оценочно усилить» — это даёт читателю **направление и обещание**.

| Нейтрально | Оценочно (Пузат) | Почему |
|---|---|---|
| точка | точка роста | направление |
| момент | важный момент | значимость |
| шаг | первый шаг (твой шаг) | подчёркивает start |
| решение | взрослое решение | оценка качества |
| 10-15 лет рутины | 10-20-30 лет делаете свое дело | активный фрейм + расширенный диапазон |

⚠️ Не злоупотреблять (1-2 на пост). Иначе становится продающим тоном.

*Источник: правки серии 2026-05-27, пост 1 v3 + пост 2 — пользователь*

## Формальное → с субъектами (от состояния к действующим лицам)

AI часто использует безличные конструкции типа «есть мнение», «существует иллюзия», «известно что». Это **формальный стиль**. Пузат говорит **через людей**.

| AI (формально, от состояния) | Пузат (через субъекты) |
|---|---|
| Есть устойчивая иллюзия. Будто X. | Многие думают, что X. |
| Существует мнение, что Y. | Люди думают, что Y. |
| Известно, что Z. | Многие знают, что Z. (или просто Z) |
| Принято считать W. | Часто слышу W. |

**Триггер для проверки:** «есть мнение», «существует иллюзия», «принято считать», «известно» → заменить на «многие думают», «люди думают», «часто слышу», «многие знают». Или просто утверждать факт без обёртки.

*Источник: правка серии 2026-05-27, пост 2 — пользователь*

## Конкретика темы (не «в наших темах», а конкретно)

Пузат **называет тему конкретно**, не обобщает. Это якорь для читателя — он понимает, о чём речь.

| Обобщённо (AI) | Конкретно (Пузат) |
|---|---|
| В наших темах | В теме доп дохода через интернет / в теме сайтов / в крипте |
| В другом направлении | В теме доп дохода в интернете |
| В нашей нише | В сайтах / в инфо-сайтах (с переводом для 40+) |
| В этой области | В теме доп дохода (или конкретно: «в сайтах») |

**Триггер для проверки:** «в наших темах», «в этой области», «в нашей нише» → заменить на конкретное название темы того поста.

*Источник: правка серии 2026-05-27, пост 2 — пользователь*

| AI (только традиционные) | Пузат (актуальные форматы) |

## Терминология платформы / продукта (брендинг)

Слова про сам продукт и людей в нём должны быть **в правильной терминологии платформы**, не школьной/тренинговой.

| AI (нейтрально/школьно) | Пузат (терминология платформы) | Почему |
|---|---|---|
| ученик | пользователь платформы / наш пользователь | не «школа», а платформа |
| марафон | программа | бренд-термин |
| схема / по той же схеме | система / по нашей системе | бренд + притяжательное «наша» |
| по инструкциям | по нашим инструкциям | притяжательное «наши» |
| доход (просто) | доп доход | всегда уточнять: ДОПОЛНИТЕЛЬНЫЙ, не вместо работы |

⚠️ Притяжательные «наша система», «наши инструкции», «наша программа» подчёркивают, что за результатом стоит платформа (а не человек сам по себе разобрался). Это часть L10 «кейс подкрепляет продукт».

*Источник: правка серии 2026-05-27, пост 3 — пользователь*

## Конкретные глаголы динамики (про цифры/доход)

Когда показываешь как менялась цифра — использовать **конкретный глагол поведения**, не «стал»/«был».

| Нейтрально (AI) | Конкретно (Пузат) |
|---|---|
| доход стал 60-100 тысяч | доход колебался между 60-100 тысячами |
| стал стабильно 300 | доход зафиксировался на уровне 300 000 |
| было 16 тысяч | доход пошёл / вышел на 16 тысяч |
| Триста. (сокращённо) | 300 000 руб в месяц (полным числом в итоге) |

**Денежные суммы в итоговых местах — полным числом цифрами** («300 000 руб в месяц»), не сокращённо («Триста»). Ясность итога.

*Источник: правка серии 2026-05-27, пост 3 — пользователь*
