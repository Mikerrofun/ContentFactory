# Генератор постов для Telegram

Стартовый проект для разработчика. Из готовой подборки авторских материалов он подбирает фрагменты по теме и запрашивает один текст у языковой модели. Ваша задача за 1–2 недели — превратить эту основу в рабочее место копирайтера с накоплением редакторского опыта. Полное задание и порядок показов описаны в [brief.md](brief.md).

## Первый запуск

Нужны Python 3.11 или новее и менеджер uv. Откройте терминал в папке с этим документом. Первый запуск скачивает зависимости и веса многоязычной модели поиска. Следующие поисковые запросы могут исполняться локально.

```sh
uv sync --frozen --extra dev
uv run --frozen python -m pytest -q
export PYTHONPATH=src
uv run --frozen python -m contentgen.index
uv run --frozen python -c 'from contentgen.retrieve import retrieve; print([(x.chunk.chunk_id, x.chunk.source_path) for x in retrieve("первые читатели блога", top_k=3)])'
```

Пример генерации после построения индекса:

```sh
uv run --frozen python -m contentgen.draft "Как блог получил первые отклики" --pillar PROOF --type история
```

Перед генерацией задайте ANTHROPIC_API_KEY через секреты среды процесса. Для выбора доступной вашему аккаунту текстовой модели задайте CONTENTGEN_MODEL. Значение по умолчанию указано в draft.py. Вызов передаёт провайдеру тему, инструкцию и подобранные выдержки и расходует средства аккаунта. Для проверки поиска и тестов ключ не нужен.

## Что где находится

| Путь | Назначение |
|---|---|
| materials/sources.json | Фиксированная подборка. Каждая запись содержит уникальный id, рубрику pillar, ссылку url на опубликованный текст и фрагмент text. Одна публикация может подкреплять несколько разных тем. |
| knowledge/VOICE.md | Образцы авторской интонации и границы использования фактуры. Прочитайте файл рядом с источниками перед первым экспериментом. |
| src/contentgen/index.py | Читает подборку, строит векторы и передаёт записи в хранилище. |
| src/contentgen/embeddings.py | Загружает модель MiniLM и преобразует русскоязычный текст в числовые векторы. |
| src/contentgen/storage.py | Сохраняет текст и метаданные в SQLite, а векторы — в массив NumPy в том же порядке. |
| src/contentgen/retrieve.py | Сравнивает вопрос с векторами фрагментов, фильтрует по рубрике и возвращает результаты с оценкой сходства. |
| src/contentgen/draft.py | Собирает тему, рубрику, образцы голоса и выдержки в запрос к Anthropic. Возвращает текст одного поста. |
| src/contentgen/config.py | Пути внутри проекта, модель поиска, размер вектора и число фрагментов выдачи. |
| corpus_index/ | Создаётся локально при первом индексировании. Содержит только производные данные поиска. |
| tests/ | Проверки хранения, подбора и сборки запроса. Ответ генератора в модульных тестах заменён контролируемым ответом. |
| pyproject.toml и uv.lock | Требования к Python и закреплённые версии зависимостей. |

Исходная команда генерации выполняет один запрос без истории выпусков. Индекс рассчитан на фиксированный комплект. Перестраивайте его при остановленном приложении. Если заменили набор целиком, укажите новую пустую папку индекса в config.py. Пустая выдача для рубрики останавливает генерацию. При ошибке доступа к языковой модели проверьте переменные среды и права на выбранную модель.

## Рубрики стартовой подборки

PROOF — наблюдаемый результат или разбор примера. METHOD — применимый способ действия. TRUST — позиция автора и основания ей доверять. HUMAN — личный взгляд. Карточка подтверждает ровно тот факт или мнение, который содержится в её тексте. Для сильного поста допустимо сузить тему. Не добавляйте цифры, истории клиентов и цитаты от лица автора для заполнения объёма.
